# U.S. Construction & Plumbing Authority — website

Static site generated by `_source/build.py` into `dist/`. The text is stored in `content/*.yml`, and the
client edits it in **Pages CMS** (config: `.pages.yml`). Each save is a commit to GitHub, and the host
rebuilds the site.

```
content/            client-editable text (site, home, pages, gallery, services/*, diagrams/*)
assets/img/uploads/ photos uploaded from the panel (resized at build time)
_source/build.py    templates + validation + build
_source/diagrams.yml diagram images and pin positions (not client-editable)
.pages.yml          Pages CMS panel (Spanish labels)
```

## Build

```
pip install -r requirements.txt
python3 _source/build.py               # -> dist/
SITE_URL=https://www.example.com python3 _source/build.py   # adds canonical URLs, og:url/og:image, sitemap.xml
```

When content is invalid (empty required field, unknown icon, wrong number of diagram point names,
missing photo…), the build stops with a list of problems in Spanish and exit code 1. The host keeps
serving the last good version.

Headings use `*asterisks*` for the red italic accent. Paragraphs support `**bold**`. All other
text is escaped.

## Hosting

**Cloudflare Pages (recommended, free, commercial use allowed)**: Workers & Pages → Create → Pages →
Connect to Git → this repo.
- Production branch: `main`
- Build command: `pip install -r requirements.txt && python3 _source/build.py`
- Build output directory: `dist`
- Environment variable: `SITE_URL=https://www.<domain>` once the domain is connected.

Cloudflare serves `/page.html` at `/page`. The build detects `CF_PAGES=1` and writes canonical URLs to
match. Response headers come from `dist/_headers`.

**Vercel**: `vercel.json` sets the same install/build/output settings and headers.

## Editing panel (Pages CMS)

1. Go to https://app.pagescms.org, sign in with GitHub and install the Pages CMS GitHub App on this repo.
2. Open the repo and the branch the site deploys from.
3. Collaborators → invite the client by email. The client signs in with an emailed code and doesn't
   need a GitHub account.

The client guide (Spanish) is in `GUIA-PANEL.md`.

`.pages.yml` is generated by `python3 _source/make_pages_config.py`. If you add an icon or a diagram,
update `ICONS` in the build or `_source/diagrams.yml`, update the matching list in the generator, and run
it again. The build rejects values it doesn't know.
